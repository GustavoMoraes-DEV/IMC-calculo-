# ⚖️ Calculadora de IMC

## 📌 Objetivo do Projeto

Projeto desenvolvido em Python para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

## 🎯 Funcionalidades

* Entrada de peso e altura.
* Cálculo do IMC.
* Classificação do resultado.
* Repetição do cálculo até o usuário decidir encerrar o programa.

## 📚 Conceitos Praticados

* Variáveis.
* Entrada e saída de dados.
* Operadores matemáticos.
* Estruturas condicionais (`if`).
* Estruturas de repetição (`while`).
* Conversão de tipos (`int` e `float`).
* Lógica de programação.
